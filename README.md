# Iron Fit

منصة لإدارة المدرب لمشتركيه: المشتركين، البرامج التدريبية، خطط التغذية، تسجيل التقدم، الرسائل، وحاسبة السعرات.
مبنية بـ Next.js 16 و PostgreSQL.

## التشغيل محليًا

المتطلبات: Node.js 20.9 أو أحدث، و PostgreSQL 14 أو أحدث.

```bash
cp .env.example .env.local      # عدّل القيم: DATABASE_URL و SECURITY_PEPPER وكلمات المرور
npm install
npm run db:init                 # ينشئ الجداول
npm run db:seed                 # ينشئ حساب المدرب وحساب مشترك تجريبي
npm run dev                     # http://localhost:3000
```

ملاحظات:
- مع قاعدة بيانات محلية بدون SSL ضع `DATABASE_SSL=disable`.
- ولّد `SECURITY_PEPPER` بالأمر `openssl rand -hex 32`.
- `npm run db:seed` و `db:init` يقرآن المتغيرات من البيئة، لذلك صدّرها أولًا: `set -a; . ./.env.local; set +a`.

## الإنتاج

```bash
npm run build
npm start
```

اضبط `NEXT_PUBLIC_APP_URL` على رابط الموقع الفعلي.

## مقاطع التمارين

- المدرب يرفع المقاطع (MP4 أو WebM أو MOV) من صفحة "مقاطع التمارين"، ويحدد إن كان المقطع لكل المشتركين أو لمشترك واحد.
- المشترك يشاهد المقاطع العامة والمقاطع المخصصة له فقط.
- الملفات تُحفظ على قرص الخادم في `UPLOAD_DIR` (الافتراضي `./storage`)، والحد الأقصى للحجم `VIDEO_MAX_MB` (الافتراضي 200).
- **مهم للنشر:** استخدم خادمًا بقرص دائم (VPS أو حاوية مع volume). الاستضافات serverless مثل Vercel لا تحتفظ بالملفات.
  للانتقال إلى S3 أو R2 لاحقًا يكفي تعديل `lib/storage.ts`.
- بعد التحديث من نسخة قديمة شغّل `npm run db:init` مرة واحدة لإضافة جدول المقاطع.

## الإعدادات

كل مستخدم (مدرب أو مشترك) يعدّل اسمه وبريده وكلمة مروره من صفحة "الإعدادات".
تغيير البريد أو كلمة المرور يتطلب كلمة المرور الحالية، وتغيير كلمة المرور يسجّل الخروج من الأجهزة الأخرى.

## الحسابات

- **المدرب**: يُنشأ بالأمر `db:seed` من `SEED_COACH_EMAIL` و `SEED_COACH_PASSWORD`.
- **المشتركون**: ينشئ المدرب حساب الدخول لكل مشترك من صفحة "المشتركين" (بريد + كلمة مرور، اختياري).
  حذف المشترك يحذف حساب دخوله أيضًا.
